# ASC 트랙 일정 → 구글 캘린더

노션 **'구글 캘린더용 DB'** 페이지를 읽어 **트랙별 구글 캘린더**를 만들고 공개한다.
멤버는 자기 트랙 캘린더 링크 하나만 구독하면 트랙 일정 + 공통 일정을 다 받는다.

> 이 스크립트는 **Google Apps Script 로 사용자 구글 계정에서** 돌아간다.
> Oracle 서버(`track-bot-api` / `track-bot`)와 무관하므로 **배포·pm2 재시작이 필요 없다.**

| 파일 | 역할 |
|---|---|
| [`Code.gs`](Code.gs) | 본 시스템. Apps Script 에 붙여넣어 실행 |
| [`asc_schedule.py`](asc_schedule.py) | 노션 표기 → 이벤트 정규화 (로컬 검증·재사용용) |
| [`build_ics.py`](build_ics.py) | `.ics` 생성. 구글 설정 없이 즉시 가져오기 |

## 표기 해석 규칙

원본이 사람이 읽는 표기라 그대로 캘린더에 못 넣는다. 아래 규칙으로 푼다.

**연도** — `날짜`에 연도가 없다. 괄호 요일이 실제로 맞아떨어지는 연도를 자동으로 고른다
(`resolveYear_`). 11기 46건은 **2026년에서만** 요일이 전부 일치했다 (2025·2027은 0건 일치).
자동 판별을 끄려면 스크립트 속성 `SCHEDULE_YEAR` 를 지정한다.

**시간** — 오전/오후를 **끝쪽에만** 적는 게 이 DB 의 관행이라, 앞쪽이 뒤쪽 표기를 물려받는다.
13 이상이면 이미 24시간 표기로 본다.

| 원본 | 해석 |
|---|---|
| `8:00-10:00PM` | 20:00 – 22:00 |
| `10:00-11:00PM` | 22:00 – 23:00 |
| `10:00-13:00AM` | 10:00 – 13:00 (끝이 13 이라 24시간 표기) |
| `7:00~10:00PM` | 19:00 – 22:00 (`~` 도 구분자로 받음) |

해석 못 하는 표기가 나오면 **예외를 던지고 멈춘다.** 조용히 건너뛰지 않는다 —
일정 하나가 소리 없이 빠지는 게 더 나쁘다.

**공통 일정 병합** — 각 트랙 캘린더에 공통 일정을 합친다. 오리엔테이션(9/6)은 트랙 DB 와
공통 DB **양쪽에** 적혀 있어 그대로 합치면 두 번 뜬다. **시작·종료가 똑같을 때만** 같은
일정으로 보고 공통 쪽을 버린다. 시간이 겹친다고 버리면 안 된다 — 9/30 외부연사특강(19–21시)과
빌더 4주차 강의(20–22시)처럼 겹치기만 하는 별개 일정이 실제로 있다.

## 셋업 (최초 1회)

1. [script.google.com](https://script.google.com) 에서 새 프로젝트 생성
2. [`Code.gs`](Code.gs) 내용을 통째로 붙여넣기
3. 왼쪽 **서비스 +** → **Google Calendar API** 추가 (식별자 `Calendar`) — **이거 안 하면 동작 안 함**
4. 노션 페이지 `구글 캘린더용 DB` 를 인테그레이션에 공유
   (페이지 우상단 `⋯` → **연결** → `ASC_BOT_TEST`). 인라인 DB 는 부모 페이지 공유를 물려받는다
5. `setSecrets_()` 의 주석을 풀고 `NOTION_TOKEN` 을 넣어 **1회 실행** → 다시 주석 처리하고 저장
6. `setup()` 실행 → 트랙 캘린더 5개 생성 + 링크 공개
7. `syncAll()` 실행 → 일정 반영
8. `listLinks()` 실행 → 실행 로그에 뜬 구독 링크를 멤버에게 공지

## 운영

- **노션 고친 뒤 `syncAll()` 다시 실행.** 몇 번 돌려도 결과가 같다(멱등).
  노션 page id 로 맞춰서 추가/수정/삭제하므로 중복이 안 생긴다.
- 노션에서 행을 지우면 캘린더에서도 지워진다.
- **손으로 넣은 일정은 건드리지 않는다.** 이 스크립트가 만든 일정에는
  `syncTag=asc-track-cal` 표식이 붙고, 그 표식이 있는 것만 대상으로 삼는다.
- 자동화하려면 **트리거 → `syncAll` → 시간 기반 → 일 단위**로 걸어둔다.
- 새 기수: 노션 DB 를 새로 만들었으면 `Code.gs` 의 `SOURCES` 와 `COHORT_LABEL` 을 갱신하고,
  `deleteAllCalendars_()` 로 지난 기수 캘린더를 정리한 뒤 `setup()` 부터 다시.
